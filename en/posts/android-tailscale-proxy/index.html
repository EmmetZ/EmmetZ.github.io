前言

最近在研究如何使用 Easytier 和 Tailscale 组网，好在手机上利用 ssh 监督电脑上的 agent 干活（感谢 Herdr 让手机也能有相当不错的终端 Agent 使用体验）。但我很快发现如果连了 Tailscale，就不是使用代理，这样我就无法在床上一边科学上网看漫画摸鱼一边使用 ssh。想完成上述目标只能不断切换 VPN，非常麻烦。

不过最近调研 Tailscale 的时候发现 Mihomo 五月就支持 Tailscale outbound 了。于是上述问题有了一个非常优雅的解决方案。

Android Apps
     │
     ▼
VPNService
     │
     ▼
Mihomo TUN
     │
     ├── 普通 Internet
     │       │
     │       ▼
     │    机场节点
     │
     └── Tailnet
             │
             ▼
        TS-OUT
             │
             ▼
       Tailscale tsnet
             │
             ▼
        Tailnet Peers

这样既可以正常使用代理，又能通过 100.x.x.x 访问 Tailnet 中的其他设备。

实施条件

  • 一台安卓手机
  • 支持覆写脚本功能的，基于 Mihomo 内核的 Android 代理客户端
  • 一个 Tailscale 账号（免费的）

本文测试时使用 Bettbox 1.19.2。

根据 Mihomo Wiki 中说明，Tailscale outbound 需要修改配置文件，应该在配置的 proxies 中添加：

- name: TS-OUT
  type: tailscale
  hostname: android-mihomo
  auth-key: tskey-auth-xxxxxxxx

但是每次更新订阅，配置文件都会刷新覆盖，所有手动编辑配置文件显然不合适。此时就可以使用客户端提供的 JS 覆写功能，每次更新时自动把上述配置添加到配置文件中。

配置

申请 Tailscale Auth Key

前往 Tailscale 控制面板申请 Auth Key：Settings → Keys → Generate Auth Key。点击跳转

覆写脚本

不想自己研究了，直接交给 GPT 老师：

const Compatible_With_Bettbox={ruleOptionsEnable:true};

function main(c){
  const N="TS-OUT",G="TAILNET";

  // 仅首次注册时需要填写 Auth Key。
  // 注册成功后保持为空即可，节点身份已保存在 state-dir 中。
  const AUTH="tskey-auth-xxxxxxxx"; 

  // 有 Tailscale Subnet Router 就填 CIDR，没有保持 [] 即可。
  const SUBNETS=[
    // "192.168.31.0/24",
    // "10.10.0.0/16",
  ];

  c.proxies=Array.isArray(c.proxies)?c.proxies:[];
  c["proxy-groups"]=Array.isArray(c["proxy-groups"])
    ?c["proxy-groups"]:[];
  c.rules=Array.isArray(c.rules)?c.rules:[];
  c.dns=c.dns||{};

  // 删除旧 TS-OUT，防止覆写重复执行后产生重复节点。
  c.proxies=c.proxies.filter(x=>x&&x.name!==N);

  const ts={
    name:N,
    type:"tailscale",
    hostname:"bettbox-android", // 填写你想要的 Tailscale Node 名称
    "state-dir":"./tailscale/bettbox",
    "accept-routes":true,
    ephemeral:false,
    udp:true
  };

  if(AUTH) ts["auth-key"]=AUTH;

  c.proxies.push(ts);

  // 创建一个只用于 UI 展示的策略组。
  c["proxy-groups"]=c["proxy-groups"].filter(
    x=>x&&x.name!==G
  );

  c["proxy-groups"].unshift({
    name:G,
    type:"select",
    proxies:[N]
  });

  // 清除之前脚本产生的规则。
  c.rules=c.rules.filter(r=>{
    if(typeof r!=="string") return true;

    const p=r.split(",");
    return p[2]!==N&&p[2]!==G;
  });

  // Tailnet 地址直接进入 TS-OUT。
  const tsRules=[
    `IP-CIDR,100.64.0.0/10,${N},no-resolve`,
    `IP-CIDR6,fd7a:115c:a1e0::/48,${N},no-resolve`,
    // Tailnet 的 MagicDNS 域名都以 ts.net 结尾，
    `DOMAIN-SUFFIX,ts.net,${N}`
  ];

  // Tailscale Subnet Router。
  for(const net of SUBNETS){
    tsRules.push(
      net.includes(":")
        ?`IP-CIDR6,${net},${N},no-resolve`
        :`IP-CIDR,${net},${N},no-resolve`
    );
  }

  // Tailscale 规则必须放在机场规则前面。
  c.rules=[
    ...tsRules,
    ...c.rules
  ];

  // MagicDNS：同样直接匹配 ts.net 后缀。
  c.dns.enable=true;
  c.dns["nameserver-policy"]=
    c.dns["nameserver-policy"]||{};

  c.dns["nameserver-policy"]["+.ts.net"]=[
    `ts://${N}`
  ];

  return c;
}

实际需要填写的只有 Auth Key（以及可选的 Subnet Router 网段）：

const AUTH="tskey-auth-xxxxxxxx";

脚本不需要 Tailnet DNS Name：Tailscale 的 MagicDNS 域名统一形如 <tailnet-name>.ts.net，所以分流规则和 DNS 策略都直接匹配 ts.net 后缀，任何 Tailnet 都适用。

Tip

这里 GPT 老师给我设计了一个 TAILNET 策略组，只是为了在 Bettbox UI 中能看到 Tailnet 流量的去向。实际上真正的 Tailnet 流量规则并没有指向 TAILNET，而是直接指向 TS-OUT。这样可以避免策略组意外选中 DIRECT 后导致 Tailscale 失效。

测试

按照上述配置后，打开代理后，可以利用 Termius 等 SSH 客户端直接访问 Tailnet 中的其他设备：

ssh user@100.x.x.x
ssh user@server.<tailnet-name>.ts.net

到此我已经成功连上了打开 SSH 服务的电脑了✌️。

Subnet Router

如果 Tailnet 中还有一台设备发布了：

tailscale up --advertise-routes=192.168.31.0/24

并且已经在 Tailscale Admin Console 中批准，那么可以修改：

const SUBNETS=[
  "192.168.31.0/24",
];

脚本会生成：

IP-CIDR,192.168.31.0/24,TS-OUT,no-resolve

之后 Android 就可以通过 Bettbox 访问：

192.168.31.10
192.168.31.20
...

这里需要注意两个不同层次：

"accept-routes":true

表示：

Tailscale tsnet
接受 Tailnet 发布的 Subnet Route

而：

IP-CIDR,192.168.31.0/24,TS-OUT

表示：

Mihomo
把这个目标网段交给 TS-OUT

两者不能完全互相替代。

小结

通过上述配置，我们成功地在 Android 上实现了 Bettbox(Mihomo) 与 Tailscale 的集成，能一边摸鱼一边干活了（）。非常简单但是很实用。

除了 Tailscale，两个星期前 Mihomo 还支持了 EasyTier 的出口。
